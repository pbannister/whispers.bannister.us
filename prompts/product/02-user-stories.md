# User stories

- As a first-time visitor, I want to upload a file without creating an account.
- As a visitor, I want clear status messages and guidance.
- As a returning visitor, I want my browser to preserve my local identity.

- As a user, I want my files to stay encrypted before and during upload.
- As a user, I want to decrypt and download files locally in the browser.
- As a user, I want to be able to share individual files with other users.
- As a user, I want some means to transfer my decryption key(s) across my devices.
- As a user, I want to be able to revoke access to my files.
- As a user, I want to be able to delete my files.
- As a user, I want to be able to specify a deletion date for a file, and have the file automatically deleted after the specified date.
- As a user, I want to be able to search for files by name or date.
- As a user, I want to be able to recover recently deleted files.
