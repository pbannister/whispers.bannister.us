# Collection Workflow Checklist

Use this checklist to validate the new collection-based workflow.

- Open the homepage and confirm that the current collection is visible.
- Create a new collection with a name and an optional description.
- Confirm that the new collection appears in the collection selector.
- Upload a file to the new collection and confirm that it appears in the file list.
- Switch to a different collection and confirm that the file list updates to the selected collection.
- Delete a file from the current collection and confirm that it is removed from the list.
- Confirm that the collection choice is preserved when the page is refreshed in the same browser.
