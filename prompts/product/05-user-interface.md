# User Interface

The user interface should present a simple and focused experience that supports collections and privacy-first file handling.

## Primary Experience
- The home page should present the current collection, the list of files in that collection, and the controls needed to upload a file.
- The home page should allow the user to create a new collection and switch between collections without leaving the page.
- The home page should allow the user to delete files from the current collection.
- The interface should provide clear status updates for uploads, downloads, key import, and errors.

## Supporting Pages
- The site should include an About page that explains the purpose of the product and summarizes the core privacy model.
- The About page should include a condensed summary of the prompts that guided the site creation.

## Collection Model
- Each collection should have a name and an optional description.
- Each collection should have a unique identifier.
- Selecting a collection should update the visible file list to match that collection.
