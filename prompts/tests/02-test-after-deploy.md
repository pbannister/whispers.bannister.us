# Tests Performed After Deploy

The following checks should be completed after deploying the site.

- As a first-time visitor, I should be able to load the homepage and see the key-management section.
- As a first-time visitor, I should be able to create a collection and upload a file to it.
- As a returning visitor, I should be able to retain my browser-stored decryption key and continue using the site without creating an account.
- As a user, I should be able to upload a file and receive confirmation that it was stored.
- As a user, I should be able to view the uploaded file in the current collection.
- As a user, I should be able to open a file, download it, and decrypt it locally in the browser.
- As a user, I should be able to delete a file from the current collection.
- As a user, I should be able to import a shared decryption key and use it to access files from another browser.
- As a user, I should be able to confirm that the site still serves the About page and contact page correctly.
